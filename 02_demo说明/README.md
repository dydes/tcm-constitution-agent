# Demo 使用说明

**https://4kyqjv7vdj1vb.aiforce.cloud/app/app_17d8emra03m**

## 功能介绍

### 输入信息
- 出生年份（自动推算天干地支）
- 出生地区（省/市两级选择，自动判定五方属性）
- 性别
- 当前年龄（根据出生年份自动计算，可微调）
- 当前居住地区（省/市两级选择）
- 职业类型（10大类40+小类，自动推算作息特点）

### 输出结果（5大模块）

1. **结论概览**
   - 人物图标剪影（按性别+年龄段生成）
   - 一句话总结
   - Top 3高风险症状

2. **五脏六腑能量变化**
   - 先天能量 vs 受影响后能量 左右对比雷达图
   - 变化影响矩阵（各因素对各脏腑的损益）
   - 先天禀赋推演步骤（可折叠，6步详细推演）
   - 后天因素影响分析（可折叠，年龄/地域/职业/情志）

3. **体质与健康风险**
   - 体质类型判定（九种体质）
   - Top 5最可能出现的症状
   - 年龄生命节律（当前阶段+下一阶段预警）
   - 组合病机分析
   - 表象清单（可折叠，按病势趋向分类）

4. **调理方案**
   - 饮食调理（按弱脏分组，每脏5种推荐食物，含图片+症状标签）
   - 运动调理（智能推荐3种最适合的运动，含3D卡通图片+功效+最佳时间+推荐理由）
   - 经络穴位（按脏推荐核心穴位，含图片+定位+功效+操作方法）
   - 起居调理（十二时辰时间轴，弱脏当令时辰高亮）
   - 情志调理（emoji卡片，五志相胜疗法）
   - 季节调理

5. **参考依据**
   - 按经典篇名分组的原文引用
   - 所有推演结论均可追溯到经典出处

### 示例数据
点击页面上的"加载示例数据"按钮，可一键加载示例：
- 1995年出生 / 河北省石家庄市 / 男 / 31岁 / 现居石家庄 / 互联网IT-程序员

## 使用方法

1. 打开在线链接
2. 填写左侧输入表单（或点击"加载示例数据"）
3. 点击"开始推演"按钮
4. 右侧展示完整推演结果，可滚动浏览5大模块
5. 点击各模块的折叠面板可查看详细推演步骤和经典依据
6. 顶部导航栏可快速跳转到各模块

## 技术特点

- 7级能量制（过强+3 / 强+2 / 偏强+1 / 平和0 / 偏弱-1 / 弱-2 / 过弱-3）
- 12种组合病机引擎（风火相煽、肺胃热盛、心肾不交等）
- 症状权重打分机制（0-100分，高/中/低风险分级）
- 病势趋向推演（火/风上炎、湿下注、寒内侵、燥伤津、气郁内郁）
- 十二经脉病候库（《灵枢·经脉》是动则病/所生病）
- 职业作息自动推演（40+职业对应15种作息标签）
- 地域气候细化（10种气候标签）
